# Dokandari (দোকানদারি) — Frontend

> Modern Bilingual Point of Sale (POS) and Inventory Management Platform tailored for Bangladesh retail businesses (৳ BDT).

## Features
- **Bilingual Interface**: Seamless instant switching between English and Bengali (**English ⇄ বাংলা**).
- **Typography**: Bengali fonts (**Hind Siliguri** + **Noto Sans Bengali**) with Bengali digit conversion.
- **Theme Support**: Smooth Dark and Light modes with local persistence.
- **POS Terminal**: Fast catalog search, category filtering, cart management, discount tags, multi-payment options (Cash, bKash, Nagad, Card), and printable thermal receipts.
- **Inventory & Stock Audit**: Low stock alerts, manual adjustments with mandatory audit trail reasons.
- **Cloud Media**: Direct ImgBB Cloud API integration with in-memory uploads and live camera capture.
- **Next.js 15 App Router**: Server-side redirects, responsive glassmorphism design with Tailwind CSS.
